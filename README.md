# Starfall Dash — Blender

Отдельный Blender-проект для визуальной разработки **Starfall Dash**.

Главная игра находится в другом репозитории:
https://github.com/wertretwetrertew-a11y/Starfall-Dash-1.1

Этот репозиторий не изменяет основной код игры. Здесь создаются 3D-сцены, концепты, анимации, рендеры и будущие ассеты.

## План

1. **Space Arena** — герой-куб, космос, планета, астероиды, кометы, враги и кристалл Космического Ядра.
2. **Boss Fights** — Космический дракон, Ледяной титан, Пожиратель звёзд.
3. **Core Crystals** — визуализация получения фрагмента Ядра.
4. **Intro** — разрушение Космического Ядра и разлёт фрагментов.

## Важное правило

Главная игра остаётся 2D. Blender используется как отдельный инструмент для сцен, концептов, референсов, эффектов и будущих ассетов.

Ничего из этого репозитория не переносится в основной репозиторий автоматически.
