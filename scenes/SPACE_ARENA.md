# Space Arena

Первая тестовая сцена Blender для Starfall Dash.

## Что внутри
- главный герой — летающий куб;
- 3 космических врага;
- кристалл фрагмента Космического ядра;
- планета и кольцо;
- астероиды и звёздный фон;
- два пролетающих комета;
- кинематографическая камера;
- свет и эффект свечения;
- базовая анимация на 180 кадров при 30 FPS.

## Запуск
1. Открой Blender 3.x/4.x.
2. Открой `scripts/space_arena.py` в Scripting.
3. Нажми Run Script.
4. Скрипт создаст сцену и сохранит `Starfall_Dash_Space_Arena.blend` рядом с ним.
5. Нажми Play Timeline для просмотра движения.

Это отдельный Blender-прототип. Репозиторий основной 2D-игры не изменяется.
